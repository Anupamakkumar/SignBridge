GETTING STARTED

How to use SignBridge

01

Listen

Open Live captions, select the spoken language, allow microphone access, and press Start listening.

02

Reply

Open Type & speak, type your response, then show the screen or select Speak message.

03

Use phrases

Choose a category and select a ready-made message for common situations.

Important limitation: This first version does not translate sign language or recognize signing from a camera. It supports speech-to-text and typed-text-to-speech, which are different capabilities. It is not a substitute for a qualified interpreter in medical, legal, or other high-stakes situations.

Browser support

Live speech recognition works best in a supported browser such as a current desktop version of Google Chrome. Some browsers do not support the Web Speech Recognition API. Text-to-speech support varies by device and installed voices.
